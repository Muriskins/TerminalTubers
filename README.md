# Terminal Tuber

Терминальный ASCII VTuber-персонаж — аватар из символов, который реагирует на звук микрофона. Говоришь — рот открывается, молчишь — рот закрывается. При каждом разговоре выбирается случайный фрейм выражения лица, создавая живой и непредсказуемый эффект.

## Быстрый старт

```bash
# Убедитесь, что установлен PipeWire или ALSA
cargo run --release
```

Готово. Персонаж появится в терминале. Говорите в микрофон — аватар реагирует. Нажмите `q` для выхода.

## Превью

```
  Рот закрыт (idle)       Рот открыт (talk)
     ╭─────────╮              ╭─────────╮
     │ ◕   ◕   │              │ ◕   ◕   │
     │    ‿    │      →       │    ▽    │  (рандомный)
     ╰─────────╯              ╰────▽────╯
```

Реальные фреймы находятся в `ascii_art/` — детализированный ASCII-арт, нарисованный вручную.

## Возможности

- Захват аудио с микрофона в реальном времени (PipeWire / ALSA)
- Случайная смена выражения лица при обнаружении голоса
- 4 стиля плавных анимаций переходов (Scramble, Collapse, Reveal, Smart)
- Возврат в idle при тишине с настраиваемой задержкой
- Интерактивное меню настроек прямо в терминале
- Выбор аудиоустройства и регулировка чувствительности
- Чистый ASCII-арт без графических оверлеев

## Система анимаций

При переходе между фреймами (idle ↔ talk) используется анимация. Доступно 4 стиля:

| Стиль | Механика | Описание |
|-------|----------|----------|
| **Scramble** | Вероятностная фиксация | Каждый символ с вероятностью `step/steps` «застывает» в целевое значение, иначе — случайный символ из набора |
| **Collapse** | Схлопывание от краёв | Символы «схлопываются» от краёв к центру по евклидовому расстоянию, на пути — collapse-символы (`/\*#@`) |
| **Reveal** | Проявление | Начинается с полного рандома, проявление с квадратичным ускорением (`progress²`) |
| **Smart** | Только изменённые | Меняются только differing-символы (позиции, где current ≠ target). Самый эффективный режим |

### Режимы Smart

| Режим | Описание |
|-------|----------|
| **Scramble** | Differing-символы крутятся через случайные символы charset, постепенно фиксируясь |
| **Instant** | Мгновенная замена (1 шаг, 50 мс задержка) |

### Волна в Smart-режиме

| Режим | Описание |
|-------|----------|
| **Random** | Случайная фиксация differing-символов |
| **Wave** | Волна от центра differing-зоны — ближние к центру фиксируются раньше |

### Наборы символов для анимаций

| Набор | Символы |
|-------|---------|
| **Classic** | `@#%*=-+:. ` |
| **Unicode** | `█▓▒░╔╗╚╝║═ ` |
| **AllPrint** | Все печатные ASCII (94 символа) |

## Установка

### Системные зависимости

| Утилита | Назначение | Обязательно |
|---------|------------|-------------|
| `pw-record` (PipeWire) | Захват аудио | Да (или `arecord`) |
| `arecord` (ALSA) | Захват аудио (fallback) | Да (или `pw-record`) |
| `pactl` | Список аудиоустройств | Нет |

Метод определяется автоматически: проверяется наличие `pw-record`, затем `arecord`.

### Rust-зависимости

```toml
crossterm = "0.27"  # управление терминалом
rand      = "0.8"   # генерация случайных чисел
```

## Управление

### Основной режим

| Клавиша | Действие |
|---------|----------|
| `q` | Выход из программы |
| `s` | Открыть меню настроек |

### Меню настроек

| Клавиша | Действие |
|---------|----------|
| `a` / `d` | Перемещение курсора вверх / вниз |
| `1`–`9` | Быстрый выбор аудиоустройства |
| `Enter` | Редактировать порог чувствительности / Применить |
| `Esc` | Отмена редактирования / Выход из меню |
| `Backspace` | Стереть символ при вводе порога |
| `q` | Полный выход из программы |

## Настройки

Меню настроек (`s`) позволяет изменить следующие параметры:

| Параметр | Описание |
|----------|----------|
| **Аудиоустройство** | Выбор источника захвата (PipeWire / ALSA / конкретное устройство) |
| **Порог чувствительности** | RMS-порог обнаружения голоса (по умолчанию: 0.01) |
| **Вкл/Выкл анимации** | Включить или отключить плавные переходы |
| **Стиль анимации** | Scramble / Collapse / Reveal / Smart |
| **Набор символов** | Classic / Unicode / AllPrint |
| **Шаги анимации** | Количество шагов перехода (больше = плавнее) |
| **Задержка анимации** | Задержка между шагами в мс |
| **Smart-режим** | Scramble / Instant |
| **Smart-волна** | Random / Wave |

## Архитектура

### Модули

| Файл | Описание |
|------|----------|
| `src/main.rs` | Точка входа: инициализация, главный цикл (ввод → RMS → смена фрейма) |
| `src/config.rs` | Структура `Config`: аудиоустройство, порог, пути к фреймам, enum-типы анимаций |
| `src/audio.rs` | `AudioCapture`: запускает `pw-record`/`arecord` как subprocess, читает raw F32 stdout, считает RMS каждые ~100 мс |
| `src/avatar.rs` | `AvatarRenderer`: alternate screen, центрирование ASCII-фрейма, 4 стиля анимации переходов |
| `src/keyboard.rs` | `poll_key()` / `try_key()` — неблокирующий ввод через `crossterm::event` |
| `src/settings_menu.rs` | `show_settings()` — рендер и обработка ввода в меню настроек |

### Логика работы

```
                    ┌──────────────┐
                    │    IDLE      │  ← idle.txt (рот закрыт)
                    └──────┬───────┘
                           │ RMS > threshold
                           ▼
                    ┌──────────────┐
                    │   TALKING   │  ← рандомный tolk0/1/2.txt
                    └──────┬──────┘
                           │ RMS < threshold + задержка
                           ▼
                    ┌──────────────┐
                    │    IDLE      │
                    └──────────────┘
```

### Аудио-пайплайн

```
  Микрофон
     │
     ▼
  pw-record --format=f32 --rate=48000 --channels=1 -
     │
     │  (raw F32 сэмплы, stdout)
     ▼
  Читаем буфер 4096 байт
     │
     │  f32::from_le_bytes()
     ▼
  RMS = sqrt(sum(s²) / n)
     │
     │  Каждые 4800 сэмплов (~100 мс)
     ▼
  AtomicU32 → main loop
     │
     │  RMS > threshold?
     ▼
  Смена фрейма / idle
```

RMS передаётся между потоками через `AtomicU32` (битовое представление f32) — lock-free и эффективный способ.

## Добавление новых фреймов

1. Создайте `.txt` файл в `ascii_art/` (например `tolk3.txt`)
2. Добавьте путь в `Config::default_config()`:

   ```rust
   talk_frames: vec![
       base.join("tolk0.txt"),
       base.join("tolk1.txt"),
       base.join("tolk2.txt"),
       base.join("tolk3.txt"),  // ← новый
   ],
   ```

3. Пересоберите: `cargo build --release`

> **Примечание:** ASCII-фреймы встраиваются в бинарник на этапе компиляции через `include_str!()`. После добавления нового фрейма требуется перекомпиляция.

## Настройка чувствительности

Порог по умолчанию: `0.01`.

| Проблема | Решение |
|----------|---------|
| Слишком часто реагирует | Увеличьте порог (0.02–0.05) |
| Слабо реагирует | Уменьшите порог (0.001–0.005) |

Изменить можно через меню настроек (`s`) или напрямую в `config.rs`.

## Производительность

| Параметр | Значение |
|----------|----------|
| Частота обновления | ~20 FPS (цикл 50 мс) |
| Обновление аудио | ~10 Гц (каждые 100 мс) |
| Зависимости | 2 крейта (crossterm, rand) |
| Внешние процессы | 1 (pw-record / arecord) |

Программа лёгкая: минимум зависимостей, работа исключительно в терминале, без графических библиотек.

## Решение проблем

### Аудио не работает

```bash
# Проверьте доступность утилит:
which pw-record  # PipeWire
which arecord    # ALSA

# Проверьте источники:
pactl list sources short
```

### Микрофон mute

```bash
pactl set-source-mute @DEFAULT_SOURCE@ 0
pactl set-source-volume @DEFAULT_SOURCE@ 100%
```

### Терминал остался в некорректном состоянии

Если после аварийного завершения терминал отображается некорректно:

```bash
reset
```
