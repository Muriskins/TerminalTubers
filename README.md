# Terminal Tuber

Терминальный ASCII VTuber-персонаж на **Go** (порт с Rust) — аватар из символов, который реагирует на звук микрофона. Говоришь — рот открывается, молчишь — рот закрывается. При каждом разговоре выбирается случайный фрейм выражения лица, создавая живой и непредсказуемый эффект.

> **Статус:** Выполняется портинг с Rust на Go (Windows-first). Фазы 1–4 (Go-фундамент, терминальный слой, захват аудио, рендер аватара и анимации переходов, главный цикл и состояния idle ↔ talking) завершены. Меню настроек — следующая фаза.

## Быстрый старт

```bash
# Требуется Go 1.26+
go run .
```

Готово. В терминале появится idle-фрейм персонажа, а в фоне запустится захват аудио с микрофона (при его наличии). Начните говорить — аватар перейдёт в состояние talking со случайным фреймом выражения лица; после ~500 мс тишины вернётся в idle. Нажмите `q` для выхода.

## Превью

```
  Рот закрыт (idle)       Рот открыт (talk)
     ╭─────────╮              ╭─────────╮
     │ ◕   ◕   │              │ ◕   ◕   │
     │    ‿    │      →       │    ▽    │  (рандомный)
     ╰─────────╯              ╰────▽────╯
```

Реальные фреймы находятся в `ascii_art/` — детализированный ASCII-арт, нарисованный вручную.

## Текущие возможности

### Реализовано (Фазы 1–4)

- Отображение ASCII-аватара в терминале (alternate screen, скрытый курсор)
- 4 встроенных фрейма: `idle` + 3 talking (`tolk0/1/2.txt`) через `go:embed`
- Центрирование фрейма с обрезкой при маленьком размере терминала
- Гарантированный восстановление терминала при любом завершении (q, ошибка, panic)
- Обработка resize с перерисовкой и перцентрированием
- Выход по `q`, `Q` или `Escape`
- Захват аудио с микрофона в реальном времени (48 кГц, моно, float32) через `malgo`
- Расчёт RMS-уровня громкости (окно 100 мс) с lock-free передачей в главный цикл
- Graceful degradation: при отсутствии микрофона — idle-аватар и уведомление
- Обработка сбоев во время сессии: watchdog и stop-колбэк → уведомление, возврат к idle
- Перечисление аудиоустройств и выбор устройства (API готов; меню настроек — Фаза 5)
- Рендер аватара: `Avatar` хранит фреймы и текущий фрейм, `PlayAnimation()` переключает фреймы
- 3 классические анимации переходов: Scramble (символы случайно циклируются и постепенно фиксируются в целевом фрейме), Collapse (символы схлопываются от краёв к центру), Reveal (случайный шум постепенно проявляет целевой фрейм)
- Smart-анимация: анимируются только символы, отличающиеся между текущим и целевым фреймом; режимы Scramble/Instant, волны Random/Wave
- 3 набора символов для анимаций: Classic, Unicode, All (весь печатный ASCII)
- Настраиваемое число шагов (1–50) и задержка шага (1–500 мс)
- Отключение анимаций → мгновенное переключение фреймов
- Главный цикл с тиком 50 мс: опрос клавиатуры и голосовой активности (FR-028)
- Состояния idle ↔ talking: 3 последовательных голосовых тика (~150 мс) → переход в talking (FR-008)
- Случайный talking-фрейм выбирается один раз за переход (FR-009, FR-011)
- Возврат в idle после тишины с настраиваемой задержкой (по умолчанию 500 мс, FR-010)
- Клавиша `s` / `S` зарезервирована под меню настроек (Фаза 5)

### Будет реализовано

- Интерактивное меню настроек прямо в терминале (включая выбор аудиоустройства и чувствительности)

## Установка

### Системные зависимости

| Требование | Значение |
|------------|----------|
| Go | 1.26 или выше |
| CGO | Требуется (аудио через `malgo` — cgo) |
| clang (MSVC target) | Требуется для cgo-сборки; вызывается через CC-обёртку `clang-wrap.exe` |

> **CC-обёртка `clang-wrap.exe`:** Go добавляет `-mthreads` к команде компилятора для windows-cgo-сборок, и clang (MSVC target) отклоняет этот флаг. Обёртка убирает его. Если `clang-wrap.exe` отсутствует в корне репозитория, пересоберите: `go build -o clang-wrap.exe clang-wrap.go`, затем зарегистрируйте: `go env -w CC=C:\путь\до\TerminalTubers\clang-wrap.exe`. Настройка `CC` — пользовательская (не репозиторная): на новой машине её нужно повторить.

### Модули Go

| Модуль | Назначение |
|--------|------------|
| `github.com/gdamore/tcell/v2` | Управление терминалом: alternate screen, raw mode, клавиатура, resize |
| `github.com/gen2brain/malgo` | Захват аудио с микрофона (WASAPI), перечисление устройств |

Зависимости подтягиваются автоматически при сборке. `tcell` написан на чистом Go, но `malgo` требует cgo — поэтому сборка возможна только с настроенной CC-обёрткой (см. выше).

## Исходный код

### Структура проекта

```
TerminalTubers/
├── ascii_art/          # ASCII-арт фреймы (idle + 3 talking)
│   ├── idle.txt
│   ├── tolk0.txt
│   ├── tolk1.txt
│   └── tolk2.txt
├── main.go             # Точка входа: загрузка фреймов, инициализация, главный цикл
├── config.go           # Конфигурация: типы анимаций, DefaultConfig()
├── assets.go           # go:embed фреймов, LoadFrames()
├── terminal.go         # Терминальный слой: tcell init, RenderFrame(), PollEvent(), Sync()
├── avatar.go           # Аватар: фреймы, текущий фрейм, PlayAnimation()
├── animation.go        # Анимации переходов: Scramble, Collapse, Reveal, Smart
├── audio.go            # Захват аудио: malgo, RMS, выбор устройства, watchdog
├── state_machine.go    # Состояния idle/talking: дебаунс голоса, возврат в idle
├── *_test.go           # Тесты (terminal, config, assets, audio, animation, state machine)
└── go.mod
```

### Модули

| Файл | Описание |
|------|----------|
| `main.go` | Точка входа: загружает 4 встроенных фрейма, инициализирует терминал, рендерит idle-фрейм, главный цикл с тиком 50 мс: PollEvent в goroutine → канал, состояния idle/talking, q/resize |
| `config.go` | Структура `Config` и `DefaultConfig()`: threshold 0.055, idle delay 500ms, анимации включены, стиль Scramble, набор Classic, 5 шагов, 30 мс задержка, Smart-режим Scramble, Smart-волна Random (хранимые в памяти, без файловой персистентности) |
| `assets.go` | `go:embed` для 4 ASCII-фреймов из `ascii_art/`, функция `LoadFrames()` |
| `terminal.go` | Терминальный слой на tcell: alternate screen, cursor hide, raw mode, центрированный рендер с top-left обрезкой, guaranteed restore через `sync.Once`, `Sync()` для перерисовки после resize |
| `avatar.go` | Аватар: `NewAvatar()`, `Render()`, `CurrentFrame()`, `Frames()`, `PlayAnimation()` — мгновенное переключение при выключенных анимациях, иначе анимация через `AnimateTransition()` |
| `animation.go` | Анимации переходов: `AnimateTransition()` (Scramble/Collapse/Reveal/Smart), 3 набора символов, Smart-режимы (Scramble/Instant) и волны (Random/Wave), шаги [1–50], задержка [1–500 мс] |
| `audio.go` | Захват аудио через `malgo`: `NewCapture()` (48 кГц моно F32), RMS за 100 мс окна в Data-колбэке, lock-free передача через `atomic.Uint32` + `math.Float32bits/Float32frombits`, graceful degradation без микрофона, watchdog + stop-колбэк для сбоев, `Devices()`/`SelectDevice()` для выбора устройства |
| `state_machine.go` | Состояния idle ↔ talking: чистый тип `StateMachine`, `Tick(voice, now)` → `Action` — дебаунс 3 голосовых тиков, случайный talking-фрейм один раз за переход, возврат в idle после idleDelay тишины (строгое `>`) |

### Текущее поведение

```
  go run .
       │
       ▼
  LoadFrames() — чтение 4 встроенных .txt фреймов
       │
       ▼
  NewTerminal() — alternate screen, cursor hide, raw mode
       │
       ▼
  NewCapture() — захват аудио с микрофона (malgo)
       │
       ├── микрофон найден → Start() — непрерывный захват, RMS каждые 100 мс
       │
       └── микрофона нет → уведомление "no microphone found", idle-аватар
       │
       ▼
  NewAvatar(frames) — аватар из 4 фреймов (frames[0] = idle)
       │
       ▼
  avatar.Render(term, idle) — отрисовка idle-фрейма по центру
       │
       ▼
  Главный цикл: select { eventCh, ticker (50 мс) }
       │
       ├── событие клавиатуры (q/Q/Escape) → return → defer Close() → восстановление терминала
       │
       ├── resize → term.Sync() → RenderFrame(avatar.CurrentFrame())
       │
       └── тик 50 мс:
           ├── capture.Err() ≠ nil → уведомление о сбое (один раз), аватар остаётся idle
           ├── voice = capture.RMS() > threshold (0.055)
           ├── sm.Tick(voice, now):
           │   ├── ActionStartTalking → случайный talking-фрейм (frames[1:]) + PlayAnimation()
           │   ├── ActionReturnToIdle → PlayAnimation(frames[0])
           │   └── ActionNone → ничего
           └── 3 голосовых тика подряд (~150 мс) → talking; 500 мс тишины → idle
```

## Добавление новых фреймов

1. Создайте `.txt` файл в `ascii_art/` (например `tolk3.txt`)
2. Добавьте путь в `frameNames` в `assets.go`:

   ```go
   var frameNames = []string{
       "ascii_art/idle.txt",
       "ascii_art/tolk0.txt",
       "ascii_art/tolk1.txt",
       "ascii_art/tolk2.txt",
       "ascii_art/tolk3.txt",  // ← новый
   }
   ```

3. Обновите директиву `go:embed` в `assets.go`:

   ```go
   //go:embed ascii_art/idle.txt ascii_art/tolk0.txt ascii_art/tolk1.txt ascii_art/tolk2.txt ascii_art/tolk3.txt
   var framesFS embed.FS
   ```

4. Пересоберите: `go build ./...`

> **Примечание:** ASCII-фреймы встраиваются в бинарник на этапе компиляции через `go:embed`. После добавления нового фрейма требуется перекомпиляция.

## Решение проблем

### Терминал остался в некорректном состоянии

При корректном завершении (q/Q/Escape) терминал восстанавливается автоматически через `defer`. Если всё-таки возникла проблема:

```bash
reset
```

### Терминал слишком маленький

Если терминал меньше размера ASCII-фрейма, изображение обрезается по верхнему левому углу. Увеличьте окно терминала.

### Нет микрофона или сбой захвата аудио

Если микрофон не найден, программа запускается с idle-аватаром и выводит в stderr:

```
TerminalTubers: no microphone found - running with idle avatar
```

При сбое захвата во время сессии (устройство остановлено или поток данных завис) выводится уведомление, а аватар остаётся в idle-состоянии. Проверьте, что микрофон подключён и не занят другим приложением, затем перезапустите программу.

### Проблемы со сборкой

```bash
# Убедитесь, что Go установлен
go version   # Должен показать 1.26+

# Установите зависимости
go mod tidy

# Соберите
go build ./...
```

Если сборка падает с ошибкой про `-mthreads` или clang, пересоберите CC-обёртку и зарегистрируйте её (см. [Системные зависимости](#системные-зависимости)).
